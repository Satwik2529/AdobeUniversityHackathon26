DETERMINISM:
  Given the same snapshot.json, every detector, the merge, the severity model and the
  ranking are deterministic - no sampling randomness, no model calls in the scoring path.
  Re-running against a live site can differ only where the site itself changed between
  fetches. To reproduce a run exactly, keep audit-output/snapshot.json and re-run the
  detectors against it with their --snapshot flag.

VERIFY_THE_ENGINE_IS_UNCHANGED:
       cd brand-ai-readiness-audit
       python3 tools/validate_marketplace.py --root . --strict     # spec conformance
       python3 tests/run_tests.py                                  # 35 fixtures, scoring, determinism
  Platform notes:
  - Run the validator on macOS, Linux or WSL. On native Windows it compares a
    backslash path against the manifest's forward-slash paths and reports every skill
    as "not listed in the manifest". That is a path-separator artefact of the checker,
    not a manifest problem; the audit itself runs normally on Windows. For the same
    reason, test layers L5 and L5b (which call the validator) fail on native Windows;
    layers L6, L0, L1, L2, L3 and L4 pass on every platform.
  - The test suite starts a local web server per fixture. On native Windows each
    fixture takes about 35 seconds, so the full suite runs for 20+ minutes. A single
    fixture can be checked quickly with:
       python3 tests/run_tests.py --only L2 --fixture F00-clean-control
