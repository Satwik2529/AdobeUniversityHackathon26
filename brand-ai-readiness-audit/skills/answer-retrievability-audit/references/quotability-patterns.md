# What makes a fact quotable

Reusable patterns behind the ANS checks. These are properties of content shape, not of
any particular site or sector.

## 1. Self-contained statement
A quotable sentence carries its own subject, its own qualifier and its own unit:
"The Model A weighs 240 grams in size 9" survives being lifted out of the page.
"It weighs 240g" does not, because the subject is elsewhere and the unit is abbreviated
inconsistently. Check: does the sentence containing the core fact also contain the entity
name or a full noun phrase naming it?

## 2. Answer first, elaboration after
The first screenful should state what the page is the answer to. A page that opens with
narrative and states the fact in paragraph nine is readable but not retrievable: the
fact is present but expensive to locate and easy to mis-attribute.

## 3. Structured facts in structured elements
Specifications belong in a table or definition list where the label and the value are
adjacent and machine-associable. The same values in a paragraph require inference to pair
them, and the same values in an image require none of the extraction to be possible at all.

## 4. Explicit units and currency
A bare number is ambiguous across markets and measurement systems. Explicit units and an
explicit currency code make a value safe to repeat.

## 5. Addressable sections
Stable heading identifiers let an answer link to the exact section rather than the page
top. A visitor arriving mid-journey then lands on the part that answers their question,
which serves both retrieval and engagement.

## 6. One canonical statement of each key fact
When the same fact is phrased five different ways across a site, all five compete. One
dated, plainly-worded canonical statement gives both machines and third parties a single
version to copy, which is how agreement across the web starts.

## 7. Question-shaped headings where the category is question-driven
Where people genuinely ask questions, headings phrased as those questions with a short
self-contained answer beneath are easy to lift. This is only worth recommending where the
question content is real. Never recommend fabricating it.
